## The feature: partner context at talk time

One feature.

Not a new operating system. Not another dashboard you babysit at 11 p.m.

When a shopper is already in the ShopGuide conversation, the agent can read the partner apps you connected and use that context in the same turn as the live catalog.

A matching review. A points balance. A list signup. A closed popup offer that would otherwise die with the modal. A Slack ping with the transcript when a human needs to take over.

The public list of those partners lives on the [integrations page](https://blog.yourshopguide.com/integrations). Six cards: Rivyo, Judge.me, Klaviyo, Smile.io, Alia, Slack. Each card leads with the merchant payoff. The how-to sits behind Learn more.

The working copy of that page is inside Shopify. Open **ShopGuide → Settings → Integrations**. ShopGuide scans the published theme and storefront assets. Apps it recognizes land at the top under "Looks like you use these," with an **On your store** badge.

That badge saves you from hunting logos. It does not invent credentials.

You still paste a token for Smile.io, Judge.me, or Rivyo. Slack still wants an incoming webhook URL. Detection is a map, not a key.

## How ShopGuide itself is wired into Shopify

Shopify integration partners only matter because ShopGuide already lives inside Shopify. Three connections. That is the product the partners attach to.

**1. Theme block.**
ShopGuide is an on-page agent. You add the ShopGuide Chat section in the theme editor. Launch messages, visibility, and styling live in the app admin. One storefront surface. Partners do not drop a second pixel farm onto the page.

**2. Shopify Admin.**
The dashboard sits in the Shopify admin sidebar. Home, Dashboard, Test your Guide, Chats, Integrations, Settings. Analytics live next to the rest of the store. There is no second login to babysit.

**3. Catalog API at talk time.**
The agent reads the live [Shopify Catalog API](https://shopify.dev/docs/api/admin-graphql) during the conversation. Stock, variants, metafields. Partner context attaches to that same turn. The shopper does not open a new tab to get any of it.

That wiring is why the partner cards exist. The page is not a logo wall. It is the list of facts the conversation can use once the catalog is already in play.

Docs also mention WhatsApp handoff and nine Sidekick tools inside Shopify Admin. Those are real. They are not tiles on the public partner page. The page is the six logos. Sidekick is native Shopify.

## Why connecting them is useful

High-SKU stores already run the standard kit. Email. Reviews. Loyalty. Something chat-adjacent. Forums keep repeating the same three complaints.

Scripts stack up. Dashboards do not share data. Two apps in the same category fight each other.

ShopGuide does not ask you to rip Klaviyo out. It asks the agent to use Klaviyo. Same for reviews and points.

The value is boring and useful.

- The review that answers "does this run large" shows up in the chat instead of on a tab the shopper never opens.
- Points become a sentence. You have 500 points. That is $5 off today.
- A closed popup is not a dead offer if the agent can bring the Alia incentive back.
- A human handoff includes the transcript, cart, and customer fields instead of "please describe your issue."

On a 200-SKU boutique that is nice. On a 10,000-SKU catalog it is how you stop the same question from becoming a ticket.

Klaviyo events the docs actually list: ShopGuide Chat Engaged, ShopGuide Order Attributed, ShopGuide NPS Submitted. Named moments. Not a mystery dump of chat logs.

## Honest limits

Say this out loud before you paste a token.

ShopGuide does not replace Klaviyo, Judge.me, Rivyo, Smile.io, Alia, or Slack. If the partner app is missing or misconfigured, there is nothing to read.

Detection only sees what is in the published theme and storefront assets. An app sitting installed but unpublished will not badge itself.

Reviews are only as good as the reviews you have. Empty review catalog means empty social proof in chat.

Smile.io only helps once the shopper is identified. A first-time anonymous visitor has no points to surface.

Slack is a one-way webhook. ShopGuide posts context into a channel. Your team still resolves in Shopify or the ShopGuide admin. You do not run the whole conversation from Slack replies.

Klaviyo still owns the flow. ShopGuide hands it the moment.

Dirty product data still produces thin answers. The Catalog API keeps stock honest. It does not write your descriptions.

A partial stack still works. You do not need every logo on the page.

That is the deal. Native wiring. Partner context when it exists. Not a new operating system.

## Frequently Asked Questions

**What are ShopGuide Shopify integration partners?**
The six apps on the [integrations page](https://blog.yourshopguide.com/integrations): Rivyo, Judge.me, Klaviyo, Smile.io, Alia, and Slack. Plus the native Shopify Catalog API the agent reads during chat.

**Do I have to replace my current apps?**
No. Keep the apps that already work. ShopGuide reads them. It does not ask you to rip Klaviyo or Judge.me out.

**How is ShopGuide integrated into Shopify?**
Three places. A theme block on the storefront. A native app in the Shopify admin for analytics and settings. Direct reads from the Shopify Catalog API during chat. Partner apps attach to that same conversation.

**How do I turn a partner on?**
Install both apps. Detection badges what it finds on the published theme. Smile.io, Judge.me, and Rivyo still need an API token. Slack needs an incoming webhook URL pasted into ShopGuide settings.

**Will this add more scripts and slow the storefront?**
ShopGuide is one theme block. Partners are not copied onto the page as extra pixels. The agent reads those systems during the conversation.

**What if I only use some of the partners?**
Use the ones you run. A store on Judge.me and Klaviyo does not need Rivyo or Alia for the agent to be useful.

**Does Slack let my team reply inside Slack?**
No. Slack gets an alert with customer, cart, and a transcript link. Resolution stays in Shopify or the ShopGuide admin so the history lives in one place.
